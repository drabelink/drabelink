## About me

Senior software engineer and independent ICT consultant with extensive
experience in Gupta SQLWindows / OpenText Team Developer since 1996.

Specialising in the analysis, maintenance, modernisation and migration
of large, business-critical enterprise applications.

Combining extensive knowledge of legacy technologies with modern
software engineering, system integration, DevOps, automation and
AI-assisted development.

Founder and maintainer of the international Team Developer Community
and creator of several publicly available developer tools.

## Core expertise

- Enterprise software engineering
- Legacy application analysis and modernisation
- Reverse engineering and source-code analysis
- Application migration and version upgrades
- Performance optimisation and refactoring
- C#/.NET and native C++ integration
- Enterprise system and database integration
- Source-control migration and repository architecture
- CI/CD, build and deployment automation
- Technical design, training and developer coaching
